MyQuizzes 1.0.0 - Ready to use
=================================

PC (Windows 10/11)  ->  folder "PC (Windows)"
  1. Double-click MyQuizzes-Setup.exe.
  2. It installs itself (no admin required) and creates the "MyQuizzes"
     icon on the Desktop and in the Start menu.
  3. On first launch, choose the language. The app starts empty: no
     subjects or quizzes until the user creates them.
  - User data is saved in Documents\MyQuizzes.
  - Uninstall: Settings > Apps > MyQuizzes > Uninstall
    (the user's quizzes in Documents are NOT deleted).
  - Note: since it is not signed with a company certificate, Windows
    SmartScreen may show "Windows protected your PC". Click
    "More info" > "Run anyway". To sell it without this warning, a
    code signing certificate is required.

ANDROID (Android 10 or higher)  ->  folder "Android"
  - MyQuizzes.apk : install directly on the phone (allow
    "install unknown apps" if prompted).
  - MyQuizzes.aab : the file uploaded to Google Play Console.

GOOGLE PLAY  ->  folder "Google Play"
  - icon-play-512.png             (store listing icon, 512x512)
  - feature-graphic-1024x500.png  (feature graphic)

Transferring quizzes between PC and phone: both on the same Wi-Fi. On
the PC, click "Connect to phone via Wi-Fi"; on the phone, tap "PC" and
enter the PIN shown on the PC.
